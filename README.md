# Hi, I'm Michal

**Accidental builder.**

I've spent 16 years in IT, with plenty of ideas and no way to code them myself. AI removed that barrier. Now I turn those ideas into useful tools, apps and automations for people and businesses.

**Now I build the things I wish existed.**

## What I'm building

- **[VibeRes](https://github.com/m-moravcik/VibeRes)** - A modern macOS menu bar resolution switcher. Built as a spiritual successor to EasyRes.
- **[Eject Guard](https://github.com/m-moravcik/eject-guard)** - A macOS menu bar utility that ejects external disks before meetings, so you can disconnect without unplugging a mounted drive.

- **[Video to Audio for Raycast](https://github.com/m-moravcik/raycast-video-to-audio)** - Extract video audio as M4A or MP3 directly from Raycast, using local ffmpeg.

## What I'm improving

- **[clings](https://github.com/m-moravcik/clings)** - My extended fork of [Drew Burchfield's Things 3 CLI](https://github.com/drewburchfield/clings), with additions including undo, reminders and headings.
